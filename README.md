3. Project Overview

Elegance Fragrance Co. is a fragrance business that provides a selection of perfumes for both women and men. The business focuses on offering fragrances that allow customers to express their individuality, confidence and personal style.

The purpose of this project is to design and develop a professional, attractive and user-friendly website for Elegance Fragrance Co. The website provides customers with information about the organisation, its products and services, as well as ways to make enquiries and contact the business.

The website is designed with a modern and elegant appearance that reflects the identity of the fragrance brand.

---

4. Website Goals and Objectives

Goals

- Create a professional online presence for Elegance Fragrance Co.
- Showcase the company's fragrance products.
- Provide customers with clear information about the organisation.
- Make it easy for customers to make enquiries and contact the business.
- Create an attractive and user-friendly website.

Objectives

- Develop a functional multi-page website using HTML and CSS.
- Provide clear and organised information about the business and its products.
- Create consistent branding across all website pages.
- Make the website easy to navigate.
- Create a responsive website that can be viewed on different screen sizes.
- Provide customers with an accessible way to learn about the company's products and services.

---

5. Key Features and Functionality

The website consists of six main pages:

- Home — Introduces Elegance Fragrance Co. and provides an overview of the website.
- About — Provides information about the organisation and its background.
- Products — Displays the available fragrances and relevant product information.
- Services — Provides information about the services offered by the organisation.
- Enquiry — Provides customers with a way to submit enquiries.
- Contacts — Provides contact information and ways to communicate with the business.

Other website features include:

- Navigation menu linking all six pages.
- Product information and images.
- Consistent branding and design.
- User-friendly page layouts.
- Responsive design.
- External CSS stylesheet.
- Footer containing relevant website information.
